Front rows

The "First N Rows" filter (N is this number) finds the first few rows of each tier; the "1st Row" filter finds just the first. This is how many count as the front, unless a venue sets its own below.

Custom badges

Tag tickets by their text. Each badge has a pattern (a regular expression, ignoring case) that's tested against everything Ticketmaster shows on the ticket: section, row, seat, ticket type ("Aisle Seating Ticket") and so on (and also against the title Section View lists the ticket under, e.g. "Row 23 (Aisle Seating Ticket)", so you can write a pattern from either). A badge shows on the tickets it matches and gets its own filter pill. For example, name: Aisle, pattern: aisle; or aisle|end of row to match either. These apply at every venue; each venue's own badges are set below, or from the 📍 button in Section View.

Pattern syntax

Patterns are JavaScript regular expressions, always ignoring case. Write just the pattern: no slashes and no flags (aisle, not /aisle/i). A pattern matches if it is found anywhere in the ticket's text, which reads like this: 

Section BLOCKG Row 26 Full Price Ticket €80.75 each

It is also tried on the ticket's title in Section View, which reads like Row 26 • Seat 12 (Aisle Seating Ticket); a ticket matches if either one does. Note the brackets there are part of that title, so (Aisle Seating Ticket) on its own is a group and matches "Aisle Seating Ticket", while \(Aisle Seating Ticket\) asks for real brackets.

aislethe word anywhere ("Aisle Seating Ticket")
aisle|end of row| means or: either phrase
\bresale\b\b is a word edge, so "presale" doesn't match
Row (21|22)\bRow 21 or Row 22, but not Row 210; brackets group
Row [A-C]\b[ ] is one character out of a set or range
BLOCK[A-G]a block from A to G
€\d\d\.\d\d each\d is a digit; \. is a literal dot
^Section BLOCKG^ and $ are the start and end of the text
seats?? makes the character before it optional
a.*b. is any character, * means any number of them

These characters have a special meaning: . * + ? ( ) [ ] { } | \ ^ $. To match one literally, put a backslash before it (\(). Letters, digits and spaces just match themselves.

Venues

Row numbers aren't the same everywhere: some venues start at Row 1, others number straight on from one tier to the next (3Arena, Dublin: the lower tier starts at Row 21 and the upper tier at Row 33), and some name their rows with letters (Row A, Row B, ... Row AA). Tell Section View where each tier starts, as numbers (21, 33) or letters (A, K), so "1st Row" and "First N Rows" mean the right thing. You can also set this from the 📍 button in Section View's header while you're on the venue's event page.
